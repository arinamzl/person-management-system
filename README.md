# person-management-system
A simple C++ person management system developed in C++ using linked lists and object-oriented programming.

Features

- Add teachers, students, and employees.
- Store personal information and identification numbers.
- Display all registered people.
- Search for and delete people by ID.

Concepts Used

- C++
- Object-Oriented Programming (OOP)
- Classes and Inheritance
- Pointers
- Linked Lists
- Dynamic Memory Allocation

How to Run

1. Clone or download this repository.
2. Open "main.cpp" in a C++ development environment.
3. Compile and run the program.

Purpose

This project was developed as a programming practice project to explore linked lists and object-oriented programming in C++.
